Linux 学习等级体系（L1-L5） ​

每个技能独立走 5 级阶梯。等级衡量的是「能做什么」，不是「背过什么」。每学完一级用 /assess <技能> <等级> 让 AI 考核，达标后再进下一级。

等级 ↔ 阶段映射以各技能 learning-path.md 为准；本文件定义每级的能力目标、常见错误、晋升标准、考核题型。

等级总览 ​

等级名称定位对应阶段考核最低分
L1新手入门跑通最小程序，建立平台认知阶段 1 · 基础层80%
L2基础能力者掌握语言核心，能写独立功能阶段 2 · 核心能力层80%
L3应用开发者能独立开发完整应用/项目阶段 3 · 工程层80%
L4资深开发者能解决生产级问题（性能/崩溃/安全）阶段 4 · 平台特性 + 资深层(前段)82%
L5专家/架构师能设计架构、主导技术决策资深层(后段) + 综合实战85%

各技能的阶段划分不同（移动端有 UI 层、Linux 无），对应到 L2/L3 时以该技能 learning-path.md 的实际阶段为准。

Level 1 · 新手入门 ​

能力目标 ​

  • 理解平台项目结构、构建与运行流程
  • 掌握变量、类型、函数、控制流
  • 能读懂并修复最简单报错
  • 建立「写 → 报错 → 改」的闭环

常见错误 ​

  1. 环境配置半途而废（下载慢/报错就放弃）
  2. > 覆盖与 >> 追加混淆（> 会清空原文件，不可逆）
  3. 相对路径与绝对路径写错，命令作用到错误位置
  4. 只读不写，没有动手闭环

晋升标准 ​

  • [ ] 独立创建项目并跑通第一个程序
  • [ ] 用本语言写一个「输入两数求和」程序
  • [ ] 能解释本平台可变/不可变语义
  • [ ] 通过 L1 考核

Level 2 · 基础能力者 ​

能力目标 ​

  • 集合/数据结构常用操作
  • 异步编程模型（协程/async-await/Promise）
  • 错误处理与空安全
  • 理解不可变性与副作用

常见错误 ​

  1. 主线程阻塞操作（移动端网络/文件阻塞 UI）
  2. 滥用强解包导致运行时崩溃
  3. 静默吞掉异常
  4. 不理解异步生命周期导致泄漏/状态错乱

晋升标准 ​

  • [ ] 实现一个「批量处理数据并输出」程序
  • [ ] 正确处理异步错误和空值（不崩溃、不静默）
  • [ ] 解释本平台异步模型的核心机制
  • [ ] 通过 L2 考核

Level 3 · 应用开发者 ​

能力目标 ​

  • 声明式 UI / 完整应用骨架
  • 组件化、状态管理、列表、导航、表单
  • 工程能力：网络、存储、依赖管理
  • 测试意识（单元/集成/UI）

常见错误 ​

  1. 状态管理混乱（该提升的没提升）
  2. 布局/组件嵌套过深
  3. 列表没有 key/复用机制
  4. 网络请求只有 happy path，缺 loading/错误态
  5. 测试只写 happy path

晋升标准 ​

  • [ ] 独立完成一个完整应用/项目（含列表/表单/持久化）
  • [ ] 能写出覆盖主要分支的测试
  • [ ] 能用调试工具定位并修复问题
  • [ ] 通过 L3 考核

Level 4 · 资深开发者 ​

能力目标 ​

  • 架构模式（MVVM/MVI 等）与分层
  • 依赖注入
  • 性能优化（重组/渲染/启动/并发）
  • 崩溃与内存问题分析治理
  • 平台特性深入（权限/通知/后台）

常见错误 ​

  1. 架构过度设计，为了模式而用模式
  2. 性能优化方向错误，不打热点
  3. 内存泄漏/崩溃只临时绕过不根治
  4. 忽视边界条件与弱网/离线场景
  5. 安全合规遗漏（混淆/签名/权限）

晋升标准 ​

  • [ ] 为一个已有项目引入架构分层与依赖注入
  • [ ] 用 profiler 定位并修复一个真实性能问题
  • [ ] 解读一次线上崩溃并给出根治方案
  • [ ] 通过 L4 考核（含架构答辩 + 性能分析）

Level 5 · 专家/架构师 ​

能力目标 ​

  • 独立设计应用架构并论证取舍
  • 并发模型深入、安全加固与发布流程
  • 国际化/无障碍/多设备适配
  • 主导代码评审、生产事故复盘
  • 沉淀自己的工程 checklist

常见错误 ​

  1. 忽视平台差异化能力（如鸿蒙分布式）
  2. 不沉淀复盘，同样的坑反复踩
  3. 发布/签名/混淆流程不了解
  4. 无法权衡架构与业务复杂度

晋升标准 ​

  • [ ] 独立完成综合实战项目（含架构设计文档 + 性能/安全考量）
  • [ ] 能设计并论证一个完整架构方案
  • [ ] 能评审他人代码并给出建设性意见
  • [ ] 通过 L5 考核（项目答辩 + 代码评审）

等级跃迁图 ​

text
L1 新手 ─(跑通最小程序)→ L2 基础能力者 ─(独立功能)→ L3 应用开发者
    ─(完整项目)→ L4 资深开发者 ─(架构与治理)→ L5 专家/架构师

使用约定 ​

  1. 每级学完用 /assess <技能> <等级> 考核，达标再升级
  2. 考核记录追加到该技能 progress.md，不覆盖历史
  3. 未通过时按 assess 给出的补学路径复习，不重复考试
  4. L4/L5 考核包含架构答辩与代码评审，不只是选择题
