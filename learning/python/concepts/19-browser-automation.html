19 · 浏览器自动化 ​

前置：18 HTML 解析与爬虫 · 预计：2.5~3 小时

概念简介 ​

上一篇的 requests 只能拿到初始 HTML。当页面是 SPA(JS 渲染)、需要交互(点击/滚动/登录)、或数据在动态加载后才出现时,requests 就无能为力了。这时需要真正的浏览器自动化:启动一个浏览器实例,让它加载页面、执行 JS、模拟交互,再提取数据。

Python 主流方案是 Playwright(微软出品,推荐)和 Selenium(老牌)。Playwright 的 Python API 与前端 JS 版几乎同构,前端工程师能零成本迁移--page.goto、page.click、page.locator、自动等待(auto-waiting)都是同一套心智模型。本篇以 Playwright 为主,覆盖同步/异步两种 API、选择器、自动等待、截图,以及登录后抓取、并发抓取等实战场景。

核心内容 ​

python
# 依赖：pip install playwright && playwright install chromium
from playwright.sync_api import sync_playwright, expect
from playwright.async_api import async_playwright
import asyncio
import json

# 1. sync API：最简单的入门方式（类比前端 Playwright 同步写法）
def scrape_with_sync():
    with sync_playwright() as p:
        # headless=False 可看到浏览器窗口（调试用）
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()

        page.goto("https://quotes.toscrape.com/", wait_until="domcontentloaded")

        # 自动等待：locator 默认会等到元素出现再操作
        quotes = page.locator(".quote")
        count = quotes.count()
        print(f"找到 {count} 条名言")

        # 提取数据：逐条遍历 locator
        results = []
        for i in range(count):
            item = quotes.nth(i)
            text = item.locator(".text").inner_text()
            author = item.locator(".author").inner_text()
            tags = item.locator(".tag").all_inner_texts()
            results.append({"text": text, "author": author, "tags": tags})

        # 截图保存（调试与存档）
        page.screenshot(path="quotes.png", full_page=True)
        # 还可导出 PDF（仅 Chromium 支持）
        page.pdf(path="quotes.pdf")
        browser.close()
        return results

# 2. 选择器：Playwright 支持多种选择策略
def selector_demo(page):
    # CSS 选择器（最常用，类比 document.querySelector）
    page.locator(".quote .text").first
    # 文本选择器
    page.get_by_text("登录")
    # 角色选择器（推荐，更稳定，类比 ARIA role）
    page.get_by_role("button", name="提交")
    # 占位符
    page.get_by_placeholder("请输入用户名")
    # label 关联
    page.get_by_label("邮箱")
    # XPath（兼容场景）
    page.locator("xpath=//div[@class='quote']")

# 3. 自动等待（auto-waiting）：Playwright 的核心优势
def auto_wait_demo(page):
    page.goto("https://example.com")
    # click 会自动等待元素可见、可点击、稳定，无需手写 setTimeout
    page.get_by_role("button", name="加载更多").click()
    # 断言式等待：expect 会轮询直到条件满足或超时
    expect(page.locator(".item")).to_have_count(10)
    # 等待特定状态
    page.wait_for_load_state("networkidle")  # 网络空闲
    page.wait_for_selector(".content")       # 元素出现

# 4. async API：配合 asyncio 并发抓取多页（性能翻倍）
async def scrape_one(playwright, url: str) -> list[dict]:
    browser = await playwright.chromium.launch(headless=True)
    page = await browser.new_page()
    await page.goto(url, wait_until="domcontentloaded")
    quotes = page.locator(".quote")
    count = await quotes.count()
    data = []
    for i in range(count):
        item = quotes.nth(i)
        text = await item.locator(".text").inner_text()
        author = await item.locator(".author").inner_text()
        data.append({"text": text, "author": author})
    await browser.close()
    return data

async def scrape_concurrent(urls: list[str]) -> list[dict]:
    """并发抓取多个 URL，asyncio.gather 同时跑多个浏览器上下文"""
    async with async_playwright() as p:
        tasks = [scrape_one(p, url) for url in urls]
        # gather 并发执行，结果顺序与 urls 一致
        results = await asyncio.gather(*tasks)
        # 展平成单列表
        return [item for page_data in results for item in page_data]

# 5. 登录后抓取：处理需要认证的页面
def scrape_after_login():
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=False)  # 登录场景开窗口便于观察
        page = browser.new_page()
        page.goto("https://quotes.toscrape.com/login")

        # 填写表单（get_by_label 最稳）
        page.get_by_label("Username").fill("admin")
        page.get_by_label("Password").fill("admin")
        page.get_by_role("button", name="Login").click()

        # 登录后等待跳转完成
        page.wait_for_url("**/quotes.toscrape.com/**")
        expect(page.get_by_text("Goodbye")).to_be_visible()

        # 持久化登录态：保存 cookies/storage，下次免登录
        context = page.context
        context.storage_state(path="auth_state.json")
        # 下次：browser.new_context(storage_state="auth_state.json")

        # 抓取登录后才可见的数据
        results = []
        quotes = page.locator(".quote")
        for i in range(quotes.count()):
            results.append(quotes.nth(i).locator(".text").inner_text())
        browser.close()
        return results

# 6. 无限滚动加载：模拟滚动到底触发加载
def scrape_infinite_scroll(page, max_scrolls: int = 5):
    items: list[str] = []
    for _ in range(max_scrolls):
        # 滚动到页面底部（类比 window.scrollTo(0, document.body.scrollHeight)）
        page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
        # 等待新内容加载
        page.wait_for_timeout(1500)  # 或 wait_for_selector 新增项
        current = page.locator(".item").count()
        if current == len(items):    # 数量不再增长，到底了
            break
        items = [page.locator(".item").nth(i).inner_text() for i in range(current)]
    return items

# 7. 运行入口
def main():
    # 同步抓取
    data = scrape_with_sync()
    print(json.dumps(data[:2], ensure_ascii=False, indent=2))

    # 异步并发抓取
    urls = [f"https://quotes.toscrape.com/page/{n}/" for n in range(1, 4)]
    all_data = asyncio.run(scrape_concurrent(urls))
    print(f"并发抓取 {len(all_data)} 条")

# Playwright 优势：自动等待、多浏览器、现代 API、async 原生支持

Python 特色:Playwright Python 版与前端 JS 版 API 几乎一一对应,page.locator / page.goto / expect 都是同名同义,前端工程师迁移成本极低;sync_playwright 用 with 上下文管理浏览器生命周期,async_playwright 配合 asyncio.gather 可并发开多个浏览器上下文实现抓取加速;自动等待(auto-waiting)是核心卖点--click()/fill() 会自动轮询直到元素可交互,无需手写 setTimeout 轮询,比 Selenium 的 WebDriverWait 更省心;storage_state 可持久化登录态实现免登录复用。

常见陷阱 ​

  • 忘记装浏览器:装完 playwright 包后必须执行 playwright install chromium 下载浏览器二进制,否则启动报错。首次安装较慢,需耐心。
  • headless 被检测:部分站点检测 navigator.webdriver 等 headless 指纹。应对:用 playwright-stealth 插件注入反检测脚本,或设 headless=False 模拟真人(更慢但更隐蔽)。
  • sync/async 混用报错:sync_playwright 与 async_playwright 不能在同一脚本混用,会抛 SyncAPIUsedInAsyncLoop。异步框架(FastAPI)里必须用 async_playwright。
  • 选择器不稳:用 get_by_role / get_by_label 比 CSS 选择器更稳(不受 class 名变动影响),这是 Playwright 官方推荐的可维护写法。
  • 资源泄漏:browser 与 context 必须关闭,否则进程残留吃内存。用 with sync_playwright() 上下文管理器确保自动清理,或 async with 对应异步版。
  • 网络等待过久:wait_until="networkidle" 会等所有请求停止,慢页面可能超时。改用 "domcontentloaded" 或 "load",按需等待特定元素。

练习建议 ​

  1. 基础:用 Playwright sync API 打开 quotes.toscrape.com,截图保存,提取首页所有名言存成 JSON
  2. 进阶:实现登录后抓取(scrape_after_login),保存登录态到 auth_state.json,第二次用 storage_state 免登录复用
  3. 综合:用 async API 并发抓取 5 个分页,用 asyncio.gather 加速,对比串行抓取的耗时差异(time.perf_counter 计时)
