11 · 导航与路由 ​

前置：10 列表渲染与虚拟滚动 · 预计：1~1.5 小时

概念简介 ​

导航解决「用户如何在多个页面之间跳转」的问题：从列表页进入详情页、返回上一页、弹出模态页、传递参数。前端用 URL 路由（React Router / Vue Router），核心是「URL 即状态」。移动端没有 URL，改用导航栈模型--每次跳转压入一个页面，返回时弹出，类似浏览器 history 但更显式。理解「栈式导航」是跨端开发的关键思维转换。

核心内容 ​

鸿蒙提供两套路由方案：旧版 Router（基于 @Entry 页面）和新版 Navigation（推荐，类似 SwiftUI 的栈模型）。

typescript
// 方案一：Navigation + NavPathStack（推荐）
@Entry
@Component
struct MainPage {
  private pathStack: NavPathStack = new NavPathStack()

  build() {
    // Navigation 是容器，管理导航栈
    Navigation(this.pathStack) {
      // 首页内容
      Column() {
        Text('首页')
        Button('查看用户 42')
          .onClick(() => {
            // 编程式跳转，带参数
            this.pathStack.pushPath({
              name: 'detail',       // 目标路由名
              param: { userId: 42 } // 携带参数
            })
          })
      }
    }
    .navDestination(this.PageMap)  // 绑定路由表
  }

  // 路由表：根据 name 返回对应页面
  @Builder
  PageMap(name: string) {
    if (name === 'detail') {
      DetailPage()
    }
  }
}

@Component
struct DetailPage {
  // 接收参数
  aboutToAppear() {
    const params = this.pathStack.getParamByName('detail')
    console.log('收到参数:', JSON.stringify(params))
  }

  @State pathStack: NavPathStack = new NavPathStack()

  build() {
    Column() {
      Button('返回')
        .onClick(() => {
          this.pathStack.pop()  // 弹栈返回
        })
      Text('用户详情页')
    }
  }
}

方案二：旧版 Router（页面级路由）：

typescript
// 在 router_map.json 中声明路由表
// 或代码跳转
import router from '@ohos.router'

// 跳转，携带参数
router.pushUrl({
  url: 'pages/DetailPage',
  params: { userId: 42 }
})

// 详情页接收参数
aboutToAppear() {
  const params = router.getParams() as Record<string, number>
  const userId = params.userId
}

// 返回
router.back()

ArkTS 特色：新版 Navigation + NavPathStack 是栈模型（推荐），旧版 Router 基于页面 URL；参数通过 pushPath({ name, param }) 传递，getParamByName 接收；路由表用 @Builder PageMap 声明。

常见陷阱 ​

  • 鸿蒙 (ArkUI)：Navigation（新版）和 Router（旧版）并存，文档和示例可能混用，初学易混淆。陷阱：NavPathStack 的 pushPath 是异步的，连续快速跳转可能栈错乱；@Builder PageMap 的路由表是条件判断字符串，没有编译期检查。
  • 共性陷阱：移动端导航是栈模型，push 太多页面（>10 层）会有内存压力；模态弹出的生命周期独立于导航栈，关闭回调时机各平台不同；深链（Deep Link）和外部跳转需要额外配置，不像前端直接改 URL。

练习建议 ​

  1. 基础：实现「列表页 -> 详情页 -> 返回」的基本导航流程，掌握跳转和参数传递的基础写法
  2. 进阶：在详情页添加「编辑」按钮，弹出模态页面（Dialog）编辑内容，保存后返回详情页并刷新数据，体会模态与栈导航的组合
  3. 综合：实现一个三级导航（首页 -> 列表 -> 详情 -> 子详情），并在返回时保持列表的滚动位置和筛选状态，体会导航栈的状态保持机制

用 /practice harmony 导航与路由 生成更多针对性练习。
